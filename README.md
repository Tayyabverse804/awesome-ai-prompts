# Awesome AI Prompts by Tayyab

A hand-picked collection of **copy-paste prompts that actually get work
done** — for coding, business, YouTube, study, jobs and blogging.
Every prompt here is tested in real daily work, not copied from a list
of lists.

**How to use:** copy a prompt, replace the parts in `[square brackets]`,
paste it into any AI assistant (ChatGPT, Claude, Gemini, Muse…).

---

## 💻 Coding & Web Development

### Explain my code like I'm a beginner
```
Explain this code to me line by line, in simple words, like I'm a
beginner. Then tell me one thing that could break it.

[paste your code]
```

### Find the bug
```
This code is not working. Expected: [what should happen].
Actual: [what happens instead]. Find the bug, explain why it happens
in 2 lines, and give me the fixed code only.

[paste your code]
```

### Build a one-page website
```
Build me a complete one-page website in a single HTML file (CSS and
JS inside it) for [business type, e.g. a bakery in Lahore].
Sections: hero, services, about, prices, contact with a WhatsApp
button. Mobile-first, fast, no external images. Use placeholder text
I can replace.
```

### Make it mobile-friendly
```
Here is my HTML/CSS. Rewrite the CSS so the page looks perfect on a
phone first, then on desktop. Keep all my content and colors the same.

[paste your code]
```

### Security check my code
```
Review this code like a security expert. List anything that could be
hacked or misused, explain each risk in one simple line, and show me
the safer version.

[paste your code]
```

## 💼 Business & Freelancing

### Client pitch (email)
```
Write a short, polite pitch email from a web developer to
[a type of business, e.g. a dental clinic] in [city] that has no
website. Offer a FREE preview of their website before they pay
anything. Keep it under 120 words, friendly, no pushy sales talk.
Add a subject line.
```

### WhatsApp pitch (short)
```
Turn this into a 3-line WhatsApp message in simple English mixed with
Roman Urdu: I make websites for small businesses, first preview is
free, here is one site I made before: [link]. Friendly, not spammy.

[your details]
```

### Reply to "price kitna hai?"
```
A client asked my price for a website but I don't want to scare them
or undersell. Write a reply that: gives a starting range, explains
what changes the price, and offers a free preview first. Polite,
short, in Roman Urdu mixed with English.
```

### Fiverr gig description
```
Write a Fiverr gig description for [service, e.g. WordPress website
design]. Title under 70 characters, 3 packages (basic/standard/
premium) with what each includes, and 5 FAQs. Honest words only —
no fake claims like "10 years experience".
```

## 🎬 YouTube & Content

### Video titles that get clicks (honestly)
```
Give me 10 YouTube title ideas for a video about [topic], for
[audience]. Rules: under 55 characters, no clickbait lies, at least
3 with numbers, at least 2 as questions. Mark your top 3 and say why.
```

### Nursery rhyme video plan
```
Plan a 90-second nursery rhyme video for [rhyme name] for a kids'
channel: break it into scenes (one line of the rhyme per scene),
describe each scene in one line for an animator, suggest thumbnail
text (max 3 words), and write a kid-safe video description with the
lyrics.
```

### Description + tags pack
```
Write a YouTube description for this video: [title]. Include: a
2-line hook, what viewers will learn/see, 3 hashtags, and 15 tags
people actually search. No spam, no unrelated tags.
```

### 30 days of content ideas
```
Make a 30-day content calendar for a [niche] channel/page. One idea
per day, each in one line, mixing: teaching, behind-the-scenes,
questions for the audience, and trends in this niche. No repeats.
```

## 📚 Study & Learning

### Explain like I'm 15
```
Explain [topic] like I'm 15 years old. Use one real-life example,
no textbook words, and finish with 3 questions to check I understood.
```

### Quiz me
```
Quiz me on [topic]. Ask one question at a time, wait for my answer,
tell me if I'm right and why, then ask the next. 10 questions,
starting easy and getting harder.
```

### English practice partner
```
Be my English practice partner. Chat with me about [topic]. After
each of my messages, quietly fix my mistakes: show the corrected
sentence in brackets, then continue the conversation naturally.
```

### Notes into flashcards
```
Turn these notes into flashcards. Front: a short question.
Back: the answer in one line. Cover every important fact, skip the
fluff.

[paste your notes]
```

## 🧑‍💼 Jobs & Career

### Build my CV
```
Make a clean one-page CV for me. I am a [role] with these skills:
[skills]. My experience: [experience or "fresher"]. My education:
[education]. Use strong action words, no fake experience, and keep
it honest and simple.
```

### Cover letter in 10 minutes
```
Write a short cover letter for this job. My skills: [skills].
The job: [paste job ad]. Match my skills to what they ask for, one
short paragraph each: why me, what I can do, closing. Honest tone.
```

### Explain this job ad
```
Explain this job ad in simple words: what the job actually is, who
can apply, what education/experience is really needed, and any
warning signs that it might be a scam.

[paste job ad]
```

### Interview practice
```
Interview me for a [job role] position. Ask one question at a time.
After each answer, give me one tip to improve it. Ask 8 questions,
including one about my weakness.
```

## ✍️ Blogging & SEO

### Blog post outline that ranks
```
Make an SEO blog post outline about [topic] for [audience in
country]. Include: a title with the main keyword, an intro plan,
H2/H3 headings that answer what people actually search, and a FAQ
section with 5 real questions.
```

### Check my post before publishing
```
Read my blog post draft and check: Is anything copied-sounding or
repetitive? Is the title clear? Does the first paragraph answer the
reader's question? List fixes in order of importance.

[paste your draft]
```

### Meta description in one line
```
Write 3 meta descriptions (under 155 characters each) for a post
about [topic]. Each must contain the main keyword and a reason to
click. No clickbait.
```

## 🌍 Daily Life

### Polish my writing
```
Rewrite this in clear, polite English. Keep my meaning exactly,
fix grammar and tone, and show me the changes you made in 1-2 lines.

[paste your text]
```

### Urdu ⇄ English, properly
```
Translate this into natural, everyday English (not word-by-word).
If I used Roman Urdu, keep the feeling of what I said.

[paste your Urdu / Roman Urdu text]
```

### Official letter / application
```
Write a formal application letter to [person/office] about
[matter]. I am [your name], [relevant detail]. Keep it respectful,
short, and in the standard format used in Pakistan.
```
