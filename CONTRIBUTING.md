# Contributing

Thanks for helping this collection grow. It stays useful by being
strict about what gets in.

## A good prompt here is

- **Tested** — you have actually used it and it worked
- **Copy-paste ready** — with `[placeholders]` where the user fills
  in their own details
- **Honest** — it does a real job: builds, explains, writes, checks
- **Clear** — one prompt, one job, written so a beginner can use it

## Not accepted

- Jailbreaks, "ignore your rules" prompts, or anything designed to
  bypass an AI's safety or a platform's rules
- Prompts for cheating: exams done dishonestly, fake reviews, fake
  experience on a CV, spam or mass unsolicited messages
- Copied collections pasted from other repos without credit
- Prompts that need someone's private data to work

## How to add one

1. Fork the repo
2. Add your prompt to the right section of `README.md`, in the same
   format: a `###` title, then the prompt in a code block
3. Say in your pull request what you used the prompt for and that it
   worked
4. One prompt per pull request keeps review fast
